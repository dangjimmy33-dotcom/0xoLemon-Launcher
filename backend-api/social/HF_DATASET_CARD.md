# 0xoLemon Public Profile Media

This dataset stores public profile cover images uploaded through 0xoLemon Launcher.
It is media hosting, not a machine-learning training dataset. Files are immutable,
content-addressed WebP images. Firestore stores the currently published pointer.

Users must confirm that a selected cover becomes publicly accessible before upload.
They may upload only content they own or are permitted to publish. Illegal, abusive,
impersonating, privacy-invasive, or copyright-infringing media is prohibited and can
be removed. Reports and deletion requests are handled through the launcher support
channel. The hosting service is best-effort; the launcher retains a local preview and
uses the previous published cover or a deterministic fallback when media is unavailable.

The repository license applies only to this dataset card and service metadata. Each
uploaded image remains subject to the uploader's rights and applicable law.
