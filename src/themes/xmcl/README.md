# XMCL theme package

This package adapts the navigation density, glass surfaces, card geometry and motion language of X Minecraft Launcher to the existing 0xoLemon React/Tauri component tree. It does not copy XMCL runtime logic or Vue components. Color Wheel remains the chroma source.

Files:
- `tokens.css`: package geometry/motion/surface tokens
- `shell.css`: compact 80px rail, titlebar and workspace anatomy
- `surfaces.css`: cards, dialogs, menus, controls and scrollbars
- `settings.css`: settings workbench adaptation
- `motion.css`: page/surface/hover motion with reduced-motion fallback
